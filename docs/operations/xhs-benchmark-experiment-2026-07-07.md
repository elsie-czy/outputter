# 小红书对标账号竞品分析实验记录

日期：2026-07-07  
对象账号：和圆子一起看网文  
实验目标：为后续“如何使用 Codex 运营小红书账号”系列教程沉淀可复用流程，同时为账号内容优化找到对标样本。

## 先给结论

第一轮不建议直接全量抓取对标账号主页和评论区。更稳的路径是：

1. 先用 3 类关键词轻量搜索，筛出账号池。
2. 用搜索卡片层数据做 15 篇爆款样本池。
3. 只挑 5 篇代表作做详情拆解。
4. 后续按天分批补充，不做高频批量爬取。

对“和圆子一起看网文”最值得参考的组合打法是：

- `Alexayal看文记录`：可信人设、书龄背书、高质感书单。
- `元宝的读书笔记`：爽点词、标题尖度、女强/天才女主包装。
- `一只订书机`：互动式选题，把读者带入“选择剧情”。
- `煎茶大师 / 阿宁的书架`：末世文搜索流量和合集标题。
- `嘟嘟酱啊啊啊 / 攒知识的小玖`：短剧爽感和女性强人设表达。

## 安全边界

本轮实验明确不做平台高频抓取：

- 不并发请求详情页。
- 不拉全量主页和全量评论。
- 不开启 `load_all_comments=true`。
- 不点赞、不收藏、不评论、不关注。
- 单轮只搜索 3-5 个关键词。
- 每个账号先抽 2-3 篇样本。
- 出现卡顿、空返回、验证码或长时间无响应，立即停止。

这套边界本身也可以写进教程：Codex 做运营分析，不等于把平台当数据库扫。

## 工具与实际情况

使用工具：

- 本机 `xiaohongshu-mcp`
- MCP 服务地址：`http://127.0.0.1:18060/mcp`
- 使用工具：`check_login_status`、`search_feeds`、少量 `get_feed_detail`

实际踩坑：

- `/health` 显示 healthy 不代表工具层已登录。
- `search_feeds` 带复杂 filters 时容易卡住；轻量参数只传 `keyword` 更稳。
- 批量 `get_feed_detail` 容易卡住，不适合一次拉 15 篇。
- Chrome fallback 需要 Codex Chrome Extension；当前 Chrome Profile 未安装扩展，所以没有继续走 Chrome 页面自动化。

本轮最终策略：

- 主要使用 `search_feeds` 的搜索卡片数据。
- 只验证性拉取了 1 篇详情，确认可以拿到正文和评论。
- 15 篇样本先做卡片层拆解，后续再分批补详情。

## 三类对标策略

### 1. 同赛道账号

目标：学习网文推荐、书荒拯救、小说安利账号的内容包装。

核心观察：

- 标题里常出现“书龄”“top”“细糠”“N刷”“书荒”等信任词。
- 书单合集比单本推荐更容易触发收藏。
- 账号人设不是“我会推荐书”，而是“我看了很多年，替你筛过”。

代表账号：

- Alexayal看文记录
- 元宝的读书笔记
- 肥皂泡泡推泡泡
- 大花的熬夜书单
- 一只订书机

### 2. 相邻高势能账号

目标：学习短剧解说、爽文剧情号的强冲突表达。

核心观察：

- 标题更情绪化，常用“好逆天”“超爽”“给跪了”“女主最强”。
- 内容不一定更精致，但滑屏钩子更直接。
- 对网文号的启发是：不要只写“推荐”，要写出“为什么爽”。

代表账号：

- 嘟嘟酱啊啊啊
- 善美鉴赏影视
- 黑桃漫
- 攒知识的小玖
- 一只订书机

### 3. 搜索流量账号

目标：学习长尾关键词和收藏型标题。

核心观察：

- 搜索词非常直白：末世文、女强文、完结文、无CP、top、合集。
- 收藏数通常高于点赞数，说明读者把它当书单工具。
- “题材 + 数量 + 质量承诺”是稳定公式。

代表账号：

- 煎茶大师
- Leery ui
- 阿宁的书架
- 喵喵唧唧
- 知与推文
- 漫卷诗书

## 第一轮标题结论

### 公式 1：书龄背书 + 重刷/N刷 + top

示例：

- `15年书龄读者｜重温多次的超好看细糠top小说`
- `一书荒就会反复重刷的小说`

可迁移到圆子账号：

- `拆了100篇后，我还会重刷的末世文`
- `书荒时反复想起的3本女强文`
- `这类文别乱追，先看这3个爽点`

### 公式 2：题材 + 数量 + 高质量承诺

示例：

- `46本高质量生存指南合集`
- `38本top级大女主文细糠`

可迁移：

- `12本末世文，女主不是来谈恋爱的`
- `9本大女主文，爽点不靠开挂`
- `7本女强文，强在脑子不是嘴硬`

### 公式 3：强爽点直接前置

示例：

- `女主是天才`
- `智商碾压超爽`
- `女主最强，一点都不憋屈`

可迁移：

- `这本女主不圣母，爽点终于对了`
- `末世文别只囤货，这本靠脑子活`
- `被轻视到反杀，这类女主太上头`

### 公式 4：互动式标题

示例：

- `拖动进度条，选择你的末世剧情`
- `你喜欢谁？`

可迁移：

- `如果穿进末世，你选哪条生存线？`
- `这3类女主，你最吃哪一种？`
- `书荒投票：你想看末世、女强还是群像？`

## 对圆子账号的改造方向

当前“和圆子一起看网文”的优势是拆解感和陪伴感，但需要更靠近小红书原生表达：

1. 标题少写“我觉得好看”，多写“读者为什么要点开”。
2. 首图大字报优先表达一个冲突，而不是完整说明一本书。
3. 正文前三行先给结论：适合谁、爽点是什么、是否值得追。
4. 评论区不要泛泛“你怎么看”，要让读者交出书名或站队。
5. 每周至少做 1 篇搜索型合集，承接长尾流量。

推荐先做 3 条内容线：

- 末世文：`末世文推荐 / 末世女主 / 囤货 / 生存指南`
- 女强文：`女强文推荐 / 大女主 / 智商碾压 / 不憋屈`
- 书荒合集：`书荒拯救 / N刷 / top / 细糠`

## 后续详情拆解计划

为了避免触发平台风控，详情拆解不一次性拉满 15 篇，改成分批：

第一批只拆 5 篇：

1. Alexayal看文记录：`15年书龄读者｜重温多次的超好看细糠top小说`

3. 一只订书机：`拖动进度条，选择你的末世剧情`
4. 阿宁的书架：`末世文天花板！46本高质量生存指南合集💪`
5. 嘟嘟酱啊啊啊：`好逆天的爽文短剧，看完我真的给跪了！`

每篇拆：

- 标题公式
- 首图大字报信息
- 正文前三行
- 置顶评论/作者评论
- 评论区读者需求
- 可迁移到圆子账号的改法

## 可转教程的文章结构

后续知识星球/Codex 实战教程可以写成：

1. 先讲结论：不要一上来全量爬，先做低频对标实验。
2. 讲反常识：MCP health 正常不等于登录态可用；搜索比详情更稳。
3. 展示流程：关键词搜索 → 账号池 → 15 篇样本 → 5 篇详情。
4. 展示安全边界：只读、低频、手动触发、不碰互动动作。
5. 展示结论：标题公式、封面公式、评论钩子。
6. 最后落到改造：圆子账号下一周怎么发。
