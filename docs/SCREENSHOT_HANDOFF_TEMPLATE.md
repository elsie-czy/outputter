## 三、执行线程工作流

收到截图任务后，执行线程必须按以下顺序处理：

1. 读取必读规范：
   - `docs/ui-rules.md`
   - `docs/开发规范手册.md`
   - 与目标页面相关的设计文档
2. 拆解截图：
   - 页面结构
   - 组件列表
   - 状态列表
   - API / 数据依赖
3. 给出实现落点：
   - 模板文件
   - CSS 文件
   - JS 文件
   - 路由 / 服务文件
4. 实现代码：
   - 新页面走 `scripts/web/routes/` + `scripts/web/templates/` + `scripts/static/`
   - 不往 `scripts/web_app_legacy.py` 增加新逻辑
5. 验证：
   - `bash scripts/check_js.sh`
   - `python scripts/web_app.py`
   - 浏览器打开目标 URL
   - 截图或描述视觉验收结果
6. 结束输出交接摘要。

## 四、还原度说明

截图开发可以高质量还原：

- 后台页面、表格、卡片、任务详情、弹窗：还原度高
- 单张图：可还原主布局和视觉风格，但交互状态需要补充说明
- 多状态图：还原度更高，尤其是空态、错误态、弹窗、移动端
- Figma：优先级最高，尺寸、间距、颜色更准确

执行时允许按 `docs/ui-rules.md` 做轻微规范化调整，例如统一圆角、按钮层级、状态颜色、字体层级。
