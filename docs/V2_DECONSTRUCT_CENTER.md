# V2 拆文中心 - 需求设计文档

> 2026-06-10 | V2.0 P0 页面

---

## 1. 设计目标

| # | 目标 | 衡量标准 |
|---|------|----------|
| 1 | 任务队列管理 | 一眼看清所有待拆解作品及状态 |
| 2 | 拆文结果展示 | 五维拆解结果（套路/人物/冲突/情绪/金句）可折叠展开 |
| 3 | 笔记生成与评分 | 笔记内容 + AI 评分可视化，低分自动标红 |
| 4 | 人工修改闭环 | 修改记录自动留存，供下次生成注入 |
| 5 | 异步生成状态 | 封面图/视频脚本队列状态实时可见 |
| 6 | 批量操作 | 多选 → 一键拆文/生成/标记 |
| 7 | 统计看板 | 今日产出、评分分布、队列完成率 |

## 3. 模块详细设计

### 3.1 左侧栏 — 任务队列

#### 3.1.1 筛选器

```
┌──────────────────────────┐
│ 🔍 搜索作品/作者...       │
├──────────────────────────┤
│ 状态:                    │
│ ☐ 排队中  ☐ 处理中       │
│ ☐ 已完成  ☐ 失败         │
├──────────────────────────┤
│ 平台:                    │
│ ☐ 起点  ☐ 晋江  ☐ 番茄   │
├──────────────────────────┤
│ 分类:                    │
│ ☐ 都市  ☐ 玄幻  ☐ 言情   │
└──────────────────────────┘
```

**数据来源**：`data/queue/deconstruct_queue.jsonl` 读队列状态，飞书选题库读平台/分类字段。

**交互**：
- 筛选即时生效，前端过滤（不额外请求）
- 支持输入搜索，前端模糊匹配作品名称+作者

#### 3.1.2 批量操作栏

```
┌──────────────────────────┐
│ 已选 3 项                │
│ [开始拆文] [生成笔记]     │
│ [生成图片] [标记完成]     │
└──────────────────────────┘
```

**按钮行为**：

| 按钮 | 前置条件 | 行为 |
|------|----------|------|
| 开始拆文 | 选中排队中的任务 | 调 API `POST /api/deconstruct/batch-start`，更新状态为 processing |
| 生成笔记 | 选中已完成拆文的 | 调 API `POST /api/note/batch-generate` |
| 生成图片 | 选中已有笔记的 | 调 API `POST /api/image/batch-generate` |
| 标记完成 | 选中已有笔记的 | 调 API `POST /api/deconstruct/batch-complete`，状态 → done |

**交互**：
- 未选任何项时，按钮置灰
- 点击后 loading 态，完成或失败 toast 提示
- 支持全选/反选

#### 3.1.3 任务列表

每条任务卡片：

```
┌──────────────────────────┐
│ ● 作品名称                │ ← 选中状态高亮
│   作者 | 起点·都市         │
│   排队中                  │ ← 状态标签颜色区分
│   [查看]                  │
├──────────────────────────┤
│ ● 作品B            ✓     │
│   作者B | 晋江·言情       │
│   已完成  评分: 85         │
│   [查看]                  │
├──────────────────────────┤
│ ● 作品C            ✗     │
│   作者C | 番茄·玄幻       │
│   失败  LLM超时           │ ← 失败原因
│   [重试] [查看日志]       │
└──────────────────────────┘
```

**状态标签颜色**：

| 状态 | 颜色 | 图标 |
|------|------|------|
| 排队中 | 灰 #9CA3AF | ○ |
| 处理中 | 蓝 #3B82F6 | ◉ 脉冲动画 |
| 已完成 | 绿 #10B981 | ✓ |
| 失败 | 红 #EF4444 | ✗ |
| 重试中 | 橙 #F59E0B | ↻ |

**数据来源**：
- 队列状态：`data/queue/deconstruct_queue.jsonl`
- 评分数据：`data/queue/quality_scores.jsonl`
- 任务详情：飞书主表记录

**交互**：
- 单击选中（高亮边框），再点取消
- Ctrl/Cmd + 点击多选
- 双击或点[查看] → 中间主区域加载该任务详情
- 列表底部显示总数 + 分页（每页 20 条）

#### 3.2.1 统计条（顶部）


**颜色规则**：
- > 85 分：绿色条 + 绿色文字 "推荐发布"
- 75-85 分：黄色条 + 橙色文字 "建议人工审核"
- < 75 分：红色条 + 红色文字 "建议重生成"
- 已重试 3 次仍 < 75：红色 + "已重试3次，请人工介入"

**重新评分**：调 LLM 评分接口（不重新生成内容）

**一键重生成**：对全部六维评分低于阈值的字段重新生成

## 4. API 设计

### 4.1 任务队列

| 方法 | 路由 | 说明 |
|------|------|------|
| GET | `/api/deconstruct/queue` | 获取队列列表，支持 ?status=&platform=&category=&q=&page=&per_page= |
| POST | `/api/deconstruct/batch-start` | body: {record_ids: [...]} ，开启批量拆文 |
| POST | `/api/deconstruct/batch-complete` | body: {record_ids: [...]} ，批量标记完成 |
| POST | `/api/deconstruct/{rid}/retry` | 重试单个失败任务 |
| GET | `/api/deconstruct/{rid}/result` | 获取单个拆文结果详情 |

### 4.2 笔记操作

| 方法 | 路由 | 说明 |
|------|------|------|
| GET | `/api/note/{rid}` | 获取笔记内容 + AI 评分 |
| POST | `/api/note/{rid}/regenerate` | 重新生成笔记，body: {fields: ["title","body","tags"], reference_ids: [...]} |
| POST | `/api/note/{rid}/save` | 保存修改，body: {title, body, tags, cta, diff_log, quality_score} |
| POST | `/api/note/batch-generate` | body: {record_ids: [...]} |
| POST | `/api/note/{rid}/score` | 重新评分 |

### 4.3 图片/视频状态

| 方法 | 路由 | 说明 |
|------|------|------|
| GET | `/api/deconstruct/{rid}/assets` | 获取封面图 + 视频脚本生成状态 |

## 6. 前端技术方案

### 6.1 不引入框架

- 继续用 Flask + Jinja2 服务端渲染
- 模板文件：`scripts/web/templates/deconstruct_center.html`
- 交互逻辑：Vanilla JS（fetch + DOM 操作）
- 样式：内联 `<style>` 或独立 `static/deconstruct.css`

### 6.2 关键 JS 模块

```javascript
// 模块划分
queue.js          // 队列列表渲染、筛选、分页
deconstruct.js    // 拆文结果面板、折叠展开、复制
note.js           // 笔记编辑区、保存、重生成
score.js          // AI 评分面板渲染
reference.js      // 参考笔记选择与注入
batch.js          // 批量操作
stats.js          // 统计条轮询刷新
```

### 6.3 实时刷新策略

| 数据 | 刷新方式 |
|------|----------|
| 队列列表 | 每 10s 轮询 `GET /api/deconstruct/queue` |
| 拆文结果 | 选中任务后单次请求，不轮询 |
| 笔记内容 | 选中任务后单次请求，手动刷新 |
| 封面图状态 | 每 5s 轮询 `GET /api/deconstruct/{rid}/assets` |
| 统计条 | 每 30s 轮询 |
