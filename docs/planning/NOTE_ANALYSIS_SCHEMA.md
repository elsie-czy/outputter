# 1.1 分析表结构建议（与 1.0 解耦）

目标：
- 1.0 继续稳定生产内容
- 1.1 独立分析结果数据并沉淀爆款因子

建议新建两张飞书表：
- `笔记结果库`（导入创作者平台导出数据）
- `爆款因子库`（周报分析后的可复用因子）
- `实验台账`（A/B 设计与结论沉淀）
- `账号7日快照`（账号层7日聚合指标）

---

## A. 笔记结果库（建议字段）

主键与基础信息：
- `笔记唯一键`（文本，唯一；由 标题+首次发布时间 hash 生成）
- `实验ID`（文本，可空；用于关联实验台账/爆款因子）
- `实验版本`（单选：A/B/NA）
- `实验变量`（文本）
- `笔记标题`（文本）
- `首次发布时间`（时间）
- `体裁`（单选：图文/视频/其他）
- `账号名`（文本）
- `恢复期标签`（单选：恢复前/恢复后/未知）
- `导入批次`（文本）
- `数据来源文件`（文本）
- `导入时间`（创建时间或数字时间戳）

原始指标（数字）：
- `曝光`
- `观看量`
- `封面点击率`
- `点赞`
- `评论`
- `收藏`
- `涨粉`
- `分享`
- `人均观看时长`
- `弹幕`

派生指标（数字）：
- `互动总量`（点赞+评论+收藏+分享）
- `互动率_按曝光`
- `收藏率_按观看`
- `评论率_按观看`
- `分享率_按观看`
- `涨粉率_按曝光`
- `爆款分`（默认权重）

默认爆款分公式（脚本内）：
`0.45*收藏率_按观看 + 0.25*评论率_按观看 + 0.2*分享率_按观看 + 0.1*涨粉率_按曝光`

---

## B. 爆款因子库（建议字段）

- `因子名称`（文本，唯一）
- `实验ID`（文本，可空；非实验场景可留空）
- `样本数`（数字）
- `均值爆款分`（数字）
- `相对全局差值`（数字）
- `收藏率（按观看）`（数字）
- `评论率（按观看）`（数字）
- `分享率（按观看）`（数字）
- `更新时间`（时间）

## C. 实验台账（建议字段）

- `实验ID`（文本，唯一）
- `实验状态`（单选：规划中/进行中/已完成/已暂停）
- `实验变量`（文本）
- `A版本说明`（文本）
- `B版本说明`（文本）
- `固定条件`（文本）
- `开始日期`（时间）
- `结束日期`（时间）
- `主指标`（文本）
- `胜出版本`（单选：A/B/平/未判定）
- `提升幅度`（数字）
- `样本数`（数字）
- `关联笔记唯一键`（文本，逗号分隔）
- `结论`（文本）
- `更新时间`（时间）

## D. 账号7日快照（建议字段）

- `快照唯一键`（文本，建议：账号名+快照日期）
- `数据类型`（单选：总体/趋势）
- `快照日期`（时间）
- `账号名`（文本）
- `导入批次`（文本）
- `数据来源文件`（文本）
- `导入时间`（时间）
- `趋势指标`（文本，趋势行使用）
- `趋势日期`（时间，趋势行使用）
- `趋势数值`（数字，趋势行使用）
- `趋势来源sheet`（文本，趋势行使用）
- `曝光`（数字）
- `观看`（数字）
- `观看率(%)`（数字，自动计算：观看/曝光*100）
- `7日波动系数`（数字，自动计算：观看趋势标准差/均值）
- `封面点击率(%)`（数字）
- `平均观看时长(s)`（数字）
- `总观看时长(s)`（数字）
- `总完播率(%)`（数字）
- `曝光环比(%)`（数字）
- `观看环比(%)`（数字）
- `封面点击率环比(%)`（数字）
- `平均观看时长环比(%)`（数字）
- `总观看时长环比(%)`（数字）
- `总完播率环比(%)`（数字）

## E. .env 配置新增

- `FEISHU_NOTE_METRICS_TABLE_ID`：笔记结果库 table id
- `FEISHU_HOT_FACTORS_TABLE_ID`：爆款因子库 table id
- `FEISHU_EXPERIMENT_LEDGER_TABLE_ID`：实验台账 table id
- `FEISHU_ACCOUNT_7D_TABLE_ID`：账号7日快照 table id

## F. 脚本使用方式

导入创作者平台 xlsx：
```bash
./.venv/bin/python scripts/note_metrics_import.py \
  --xlsx "/Users/lalalaba/Downloads/截止3.1笔记内容数据.xlsx" \
  --batch 2026-03-02 \
  --account-name "主账号" \
  --recovery-date 2026-03-01 \
  --write-feishu
```

生成爆款基因周报：
```bash
./.venv/bin/python scripts/hot_model_report.py --days 14
```

生成周报并同步因子到飞书：
```bash
./.venv/bin/python scripts/hot_model_report.py --days 14 --sync-factors
```

仅分析某个实验ID：
```bash
./.venv/bin/python scripts/hot_model_report.py --days 14 --experiment-id exp_20260302_title --sync-factors
```

登记/更新实验台账：
```bash
./.venv/bin/python scripts/experiment_ledger_upsert.py \
  --experiment-id exp_20260302_title \
  --status 进行中 \
  --variable 标题钩子 \
  --a-desc "痛点直给型标题" \
  --b-desc "反差悬念型标题" \
  --controls "题材/长度/发布时间固定" \
  --start-date 2026-03-02
```

导入7日观看快照：
```bash
./.venv/bin/python scripts/account_7d_import.py \
  --xlsx "/Users/lalalaba/Downloads/近7日观看数据.xlsx" \
  --batch 2026-03-03 \
  --account-name "主账号" \
  --snapshot-date 2026-03-03 \
  --write-feishu
```
说明：该脚本会读取 xlsx 的全部 sheet（总体 + 趋势），并一起写入同一张“账号7日快照”表。

## G. 解耦原则

- 1.0 主流程不依赖上述两张分析表
- 1.1 分析失败不影响 1.0 内容生产
- 仅在你确认可用后，再把“爆款因子建议”作为可选提示回流到 1.0
