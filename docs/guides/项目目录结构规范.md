## 二、目录职责

### scripts/

项目所有 Python 代码。顶层目录放独立脚本，`scripts/web/` 放 Web 应用模块。

| 子目录 | 职责 | 规则 |
|--------|------|------|
| `web/routes/` | Flask Blueprint 路由 | 每个新功能一个 Blueprint 文件 |
| `web/services/` | 业务逻辑 | 纯函数，不依赖 Flask request context |
| `web/templates/` | Jinja2 模板 | 页面组件放根目录，可复用宏放 `_components/` |
| `web/static/` | CSS/JS/图片 | 不写内联样式/脚本到 HTML |

### docs/

全部项目文档。`INDEX.md` 是总入口；根目录只保留全局索引和变更记录。项目总览放 `overview/`，规划设计放 `planning/`，开发协作规范放 `guides/`，运维部署和主线程任务单放 `operations/`。

### data/

本地持久化数据。`topic_library.jsonl` 是选题本地缓存，`queue/` 是 V2 任务队列。

### outputs/ / logs/ / temp/ / .venv/

全部 gitignore。运行时产物不应进入版本控制。

## 三、命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| Python 文件名 | snake_case | `model_adapter.py` |
| Python 类名 | PascalCase | `FeishuClient` |
| Python 函数名 | snake_case | `analyze_work()` |
| Jinja2 模板文件 | snake_case | `deconstruct_center.html` |
| Jinja2 组件文件 | snake_case | `status_badge.html` |
| CSS 文件名 | snake_case 或 kebab-case | `base.css` |
| JS 文件名 | snake_case | `queue.js` |
| JSONL 文件名 | snake_case | `deconstruct_queue.jsonl` |
| 分支名 | `feature/` 或 `hotfix/` + kebab-case | `feature/v2-frontend-arch` |
| 文档文件名 | 中文或英文 | `V2_PLAN.md` |
| 提交信息 | `<type>: <中文描述>` | `feat: 批量拆文队列` |

## 五、与 generate-video 原规范的差异

本项目不是 generate-video 的子项目，差异较大：

| 方面 | generate-video | personal-supertool |
|------|---------------|-------------------|
| 语言 | Python 3.12+ | Python 3.11 |
| Web 框架 | FastAPI (async) | Flask (sync) |
| 包管理 | uv + pyproject.toml | pip + requirements.txt + venv |
| 前端 | Next.js + TypeScript | Jinja2 模板 + Vanilla JS |
| 渲染 | Remotion (Node.js) | 无 |
| 容器 | Docker（多服务） | Docker（三服务） |
| 数据库 | config.json 文件 | 飞书多维表格 + JSONL |
| 分支基线 | `feature/sprint4-stability` | `main` 直接分支 |

已删除不适用规则：
- TypeScript/React/Next.js 规范
- Remotion 渲染规范
- 前端 page.json 开发工作流
- 异步编程规范（Flask 同步模式）
